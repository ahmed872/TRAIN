# نظام إدارة المستشفى (Hospital Management System)

تطبيق ويب بسيط بـ PHP و MySQL لإدارة الأقسام والأطباء والمرضى والمواعيد
والسجلات الطبية، مع نظام صلاحيات على أربعة مستويات.

## المتطلبات

- PHP 8.1 أو أحدث (بامتداد `pdo_mysql`)
- MySQL 5.7+ أو MariaDB 10.3+
- خادم ويب (Apache أو Nginx أو خادم PHP المدمج)

## التنصيب

1. **إنشاء قاعدة البيانات.**

   لو ده تنصيب جديد من الصفر:

   ```bash
   mysql -u root -p < schema.sql
   ```

   أما لو عندك داتابيز `hospital` شغالة من قبل وفيها بيانات، فـ `schema.sql`
   **مش هيعمل حاجة** لأنه بيستخدم `CREATE TABLE IF NOT EXISTS` وبالتالي بيتخطى
   الجداول الموجودة. في الحالة دي استخدم ملف الترقية:

   ```bash
   mysql -u root -p hospital < migrate.sql
   ```

   ملف الترقية بيضيف عمود `users.patient_id`، ودور `patient`، والقيود اللي
   بتمنع الحجز المزدوج وتكرار السجلات الطبية، والمفاتيح الأجنبية. وهو آمن
   للتشغيل أكتر من مرة، وبيبدأ بفحص البيانات المكررة قبل ما يعدّل أي حاجة —
   فلو لقى تعارض بيقف ويقول لك إيه المشكلة من غير ما يغيّر أي شيء.

2. **ضبط بيانات الاتصال** عبر متغيرات البيئة (اختياري — القيم الافتراضية
   مناسبة لبيئة التطوير المحلية):

   ```bash
   export DB_HOST=localhost
   export DB_NAME=hospital
   export DB_USER=root
   export DB_PASS=secret
   ```

3. **تشغيل التطبيق:**

   ```bash
   php -S localhost:8000
   ```

   ثم افتح <http://localhost:8000>.

## أول تسجيل دخول

| اسم المستخدم | كلمة المرور   |
| ------------ | ------------- |
| `admin`      | `Admin@12345` |

> ⚠️ غيّر كلمة المرور دي فورًا من صفحة «المستخدمون» بعد أول دخول.

## الصلاحيات

| الصلاحية       | الأقسام والأطباء والمرضى | المواعيد   | السجلات الطبية    | المستخدمون |
| -------------- | ------------------------ | ---------- | ----------------- | ---------- |
| مدير النظام    | عرض وتعديل وحذف          | كامل       | كامل              | كامل       |
| موظف استقبال   | عرض وتعديل               | عرض وتعديل | —                 | —          |
| طبيب           | عرض                      | مواعيده هو | سجلات مرضاه هو    | —          |
| مريض           | عرض الأقسام والأطباء     | مواعيده هو | —                 | —          |

حسابات الأطباء وموظفي الاستقبال والمديرين بيضيفها المدير من صفحة «المستخدمون».
صفحة إنشاء الحساب العامة بتنشئ حسابات مرضى فقط.

## بنية المشروع

```
├── assets/css/       ملفات التنسيق
├── config/           إعدادات التطبيق والاتصال بقاعدة البيانات
├── includes/         الجلسات والصلاحيات والهيدر والفوتر ودوال التحقق
├── auth/             تسجيل الدخول وإنشاء الحساب وتسجيل الخروج
├── departments/      إدارة الأقسام
├── doctors/          إدارة الأطباء
├── patients/         إدارة المرضى
├── appointments/     إدارة المواعيد
├── medical_records/  إدارة السجلات الطبية
├── users/            إدارة المستخدمين (للمدير فقط)
├── schema.sql        بنية قاعدة البيانات (تنصيب جديد)
└── migrate.sql       ترقية قاعدة بيانات موجودة
```

## ملاحظات أمنية

- كلمات المرور مخزّنة بـ `password_hash()` ومتحقق منها بـ `password_verify()`.
- كل استعلامات قاعدة البيانات بتستخدم prepared statements.
- كل العمليات اللي بتغيّر بيانات بتتم عبر POST ومحمية بتوكن CSRF.
- الجلسة بتتجدد عند تسجيل الدخول، وكوكي الجلسة `HttpOnly` و `SameSite=Lax`.
